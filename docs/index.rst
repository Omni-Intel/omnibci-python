OmniBCI Python SDK
==================

OmniBCI Python SDK（包名 ``omnibci``）通过 Rust SDK 连接 ESP32-C3 + ADS1299
八导及 STM32/E73 32 导设备，支持 USB 串口和 BLE，提供 250 Hz EEG 采集、前端配置和 NumPy 数据转换。

版本：|release|。
